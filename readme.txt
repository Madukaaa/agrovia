Agrovia is a modern, standalone WordPress theme engineered for sustainable agriculture, regenerative farming, environmental stewardship, and agri-tech innovation.

== Description ==

Agrovia is crafted specifically for organic farms, agri-tech innovators, sustainable agriculture cooperatives, and regenerative agriculture enterprises. Designed as a standalone classic/hybrid theme, Agrovia delivers deep Elementor integration, refined WooCommerce support, and an accessible, responsive experience without third-party theme dependencies.

Key Features:
* **Standalone Architecture**: 100% self-sufficient; zero dependency on parent themes like Astra or Hello Elementor.
* **Elementor Pro Theme Builder Compatible**: Full support for Header, Footer, Single Post, Archive, 404, and Single Product custom locations.
* **Companion Plugin Included**: Agrovia Core powers agricultural post types (Farm Practices, Team) and 6 custom Elementor widgets.
* **Design-System Driven**: Unified color tokens, typography scales, and spacing synchronized between `theme.json`, Elementor Global Styles, and CSS custom properties.
* **WooCommerce Ready**: Beautifully styled store templates, product grids, cart, checkout, and account pages.
* **Accessibility Focused**: WCAG 2.1 AA compliant color contrast, skip-to-content links, screen reader text, keyboard navigable navigation menus, and semantic HTML5 hierarchy.
* **Performance Engineered**: Zero jQuery dependencies, native CSS variables, preconnect resource hints, script deferral, and high-priority LCP image optimization.

== Installation ==

1. In your WordPress admin dashboard, navigate to **Appearance > Themes**.
2. Click **Add New** and then **Upload Theme**.
3. Select the `agrovia.zip` file and click **Install Now**.
4. Once installed, click **Activate**.
5. Install and activate the companion plugin **Agrovia Core** located in `companion-plugin/agrovia-core/` or from your package.
6. (Optional) Install and activate **Elementor** and **WooCommerce** for full builder and eCommerce capabilities.
7. Navigate to **Tools > Import** to import demo content or use the Elementor Kit import wizard.

== Frequently Asked Questions ==

= Does Agrovia require Elementor to function? =
No. Agrovia includes complete classic PHP fallback templates for all views (Header, Navigation, Blog, Single, Archives, Search, 404, WooCommerce). Elementor is fully supported for users who prefer visual page building.

= Can I use Agrovia with block-based Gutenberg editing? =
Yes. Agrovia includes a comprehensive `theme.json` (v3) configuration that integrates the theme color palette, typography font families, and spacing into the WordPress block editor.

= How do I customize theme colors? =
You can customize theme colors via **Appearance > Customize > Colors & Branding** in the WordPress Customizer, or via Elementor Global Colors if using the Elementor Kit.
